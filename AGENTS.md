# Osura interactive demo

Standalone React/Vite supplier-assurance prototype deployed on Vercel. All data is synthetic; changes live in memory until refresh. Public seed JSON and the demo-user selector are not real authentication or tenant security.

Current stage: the owner explicitly approved the original CONCEPT-01–CONCEPT-16 layouts and interactions from `Osura Decision Call.html`, in addition to the D01–D16 correctness fixes. Earlier final-call-sheet deferrals no longer exclude the guided example, scoped record search, mobile service cards, executive decision layout, expandable service directory or versioned supplier corrections. See `docs/approved-v2-changes.md` and `docs/decision-file-completion.md` for the implementation crosswalk and verification status. Customer, Analyst and Superadmin roles retain assigned-customer access and named review history. The current visual revision targets the separate `osura-v2.dev.fems.education` demo; source changes do not update that manual Coolify deployment automatically (build a release image on `ois@172.30.18.16` and update Coolify service `ebmzph9q24sckudcsrr8y0eh`). The original demo remains a separate snapshot.

The latest client-handover corrections and live release evidence are in `docs/client-handover-fixes-2026-11-07.md`. Handoffs require both accessible engagement and matching workspace IDs, live Cedar readiness, and readable wrapping text. Bootstrap JSON/schema requests bypass HTTP cache; the v2 Nginx metadata location returns `Cache-Control: no-store`.
